# Power Platform Drill

A 100-question interview-prep quiz covering Power BI, Power Apps, Power Automate, Power Platform integration, and maintenance-ops terminology (WR, WO, PM, PM Deferral).

Open `index.html` in any browser to take the quiz. No build step, no dependencies — it's a single self-contained HTML file.

Enable GitHub Pages (Settings → Pages → deploy from `main`) to get a hosted link.
